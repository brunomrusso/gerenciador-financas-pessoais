🏗 Arquitetura

Arquitetura clássica em 3 camadas (cliente → API REST → banco). O frontend é um SPA Svelte que comunica com a API Flask via fetch + JWT. O backend usa Blueprints para organizar rotas por domínio.

flowchart LR subgraph Cliente["🌐 Cliente (SPA)"] UI[Svelte Components] ST[Stores Reativos] UT[Utils / Format] UI --> ST UI --> UT end subgraph API["⚙️ API Flask"] AUTH[/auth_routes/] REC[/records_routes/] ACC[/accounts_routes/] CARD[/cards_routes/] INV[/investments_routes/] JWT{JWT Middleware} AUTH --> JWT REC --> JWT ACC --> JWT CARD --> JWT INV --> JWT end subgraph DB["🗄 PostgreSQL"] USR[(users)] MR[(monthly_records)] EXP[(expenses)] DSC[(discounts)] SAL[(salaries)] TRF[(transfers)] FA[(financial_accounts)] CC[(credit_cards/expenses)] IA[(investment_accounts/transactions)] CAT[(categories)] TB[(tag_budgets)] end Cliente -- HTTPS + Bearer JWT --> API JWT -- SQLAlchemy ORM --> DB

🎯 Camada de Apresentação

16 componentes Svelte isolados, stores reativos para auth/contas/tema/privacidade. Reatividade fina ao alterar mês/registro.

🔄 Camada de Aplicação

5 Blueprints Flask (auth, records, accounts, cards, investments). Validação inline, agregações em SQL, JWT em todas as rotas privadas.

💾 Camada de Persistência

14 tabelas relacionais com FKs e índices em user_id/record_id. Migrações idempotentes via ALTER TABLE IF NOT EXISTS.

✨ Funcionalidades

📅 Registros mensais

Um registro por mês/ano com salário bruto, saldo anterior e relacionamentos.

🏦 Múltiplas contas

Corrente, poupança, carteira, etc. Saldo calculado em tempo real considerando todos os fluxos.

💵 Despesas

Crédito ou débito, recorrentes, com tags e categorias.

💳 Cartões parcelados

Compras com parcelamento automático (group_id) distribuídas nas faturas futuras.

📈 Investimentos

Aporte, saque e rendimento — com conta financeira de origem/destino.

🔁 Transferências

Entre contas, sem afetar o saldo líquido total.

💰 Salários múltiplos

Salário principal + adicionais (freela, bônus) em contas distintas.

📊 Painel analítico

6 KPIs: taxa de poupança, comprometimento, burn rate, runway, variação patrimônio, total economizado.

🎯 Orçamentos

Por categoria e por tag, com progresso e alertas.

📜 Histórico unificado

Timeline por conta com todos os tipos de evento.

🙈 Modo privacidade

Oculta valores na tela com um clique (persistido em localStorage).

🌓 Tema claro/escuro

Toggle no header, persistente.

📥 Export Excel

Download do mês completo via openpyxl.

🔁 Recorrentes

Botão "Copiar recorrentes" replica despesas/descontos do mês anterior.

📱 Mobile responsivo

Tabelas com scroll, colunas hide-sm, botões touch-friendly.

🔐 Autenticação & Segurança

  • 🔑 JWT assinado pelo backend (Flask-JWT-Extended)
  • 🔒 Senhas armazenadas com werkzeug.security.generate_password_hash (PBKDF2)
  • 🛡 Toda rota protegida por @jwt_required() e filtra por user_id do token
  • 🌍 Flask-CORS liberado em /api/* para o domínio do frontend
  • 💾 Token persistido em localStorage e enviado em Authorization: Bearer <jwt>
  • ♻️ Logout limpa token e redireciona para /login
