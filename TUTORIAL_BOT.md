# 🤖 Bot do CashFlow no Telegram

Lance suas despesas, receitas e transferências direto do celular, em segundos. Sem precisar abrir o site.

---

## 📋 O que dá pra fazer pelo bot

- 💸 **Lançar despesa** (com conta, valor, descrição, categoria)
- 💰 **Lançar receita** (entrada de dinheiro)
- 🔁 **Transferir** entre suas contas
- 📊 **Ver saldo** de todas as contas
- 📋 **Resumo do mês** (receitas, despesas e saldo)

Tudo salvo automaticamente no seu painel CashFlow.

---

## 🔧 Como configurar (uma única vez, leva 1 minuto)

### Passo 1 — Abra o bot no Telegram

Procure por **@meucashflow_bot** ou clique no link:

👉 [https://t.me/meucashflow_bot](https://t.me/meucashflow_bot)

Toque em **▶ Iniciar / Start**.

O bot vai responder com instruções de boas-vindas.

---

### Passo 2 — Gere seu código de vinculação no app

1. Acesse o **CashFlow** no navegador (ou app)
2. Clique no seu **avatar** no canto superior direito
3. Role até a seção **🤖 Telegram**
4. Clique em **Gerar código de vinculação**

Vai aparecer um código de 6 dígitos, tipo:

```
   847391
```

> ⏱ **O código expira em 10 minutos.** Se demorar, gere outro.

---

### Passo 3 — Envie o código no bot

Volte para o Telegram e envie:

```
/start 847391
```

*(troque pelo seu código real)*

✅ Pronto! O bot vai responder confirmando a vinculação. **Você não precisa fazer isso de novo** — da próxima vez é só mandar mensagem.

## 💬 Como usar no dia-a-dia

### Menu principal

A qualquer momento envie:

```
/menu
```

Aparece uma tela com botões:

```
[ 💸 Despesa ]   [ 💰 Receita ]
[ 🔁 Transferência ]  [ 📊 Saldo ]
[ 📋 Resumo do mês ]
```

Toque no botão e siga o fluxo. O bot vai te guiar passo a passo.

---

### Exemplo: lançar uma despesa

1. Toque em **💸 Despesa**
2. Escolha a conta (Nubank, Caixa, Carteira…)
3. Digite o **valor**: `45.90`
4. Digite a **descrição**: `Almoço`
5. Escolha a **categoria** (Alimentação, Transporte…)
6. Toque em **Confirmar** ✅

Pronto! A despesa aparece imediatamente no seu painel.

---

### Comandos rápidos

| Comando | O que faz |
|---|---|
| `/menu` | Abre o menu principal |
| `/saldo` | Mostra saldo de cada conta + total |
| `/start` | Mensagem de boas-vindas |
| `/unlink` | Desvincula este celular do app |

## ❓ Perguntas frequentes

**O bot é seguro?**
Sim. Cada usuário tem seu próprio vínculo, com código único e expirável. Ninguém vê os dados dos outros.

**Posso usar em mais de um celular?**
Sim, mas só **um por vez**. Se vincular outro celular, o anterior é desvinculado automaticamente.

**Esqueci de gerar o código antes de mandar /start, o que faço?**
Sem problema. Volte ao app, gere o código, e envie `/start CODIGO` no bot. Ele aceita a qualquer momento.

**Posso editar/excluir o que lancei pelo bot?**
Sim — abra o app web normalmente. Tudo o que o bot cria é igual ao que você criaria manualmente.

**O bot demora pra responder a primeira mensagem?**
Pode demorar até 30 segundos na primeira interação do dia (servidor "acordando"). Depois fica instantâneo.

**Como desvincular?**
No bot, envie `/unlink`. Ou no app, em **Avatar → 🤖 Telegram → Desvincular**.

---

## 🆘 Algo deu errado?

- **Bot não responde** → aguarde 30s e tente de novo. Se persistir, gere outro código no app.
- **Código inválido / expirado** → gere um novo (válido por 10 min).
- **Não acho minha conta na lista** → verifique se ela está marcada como **ativa** no app.
