🚀 FLUXO RECOMENDADO:

PRIMEIRA VEZ (Instalação Completa):
  1. powershell -ExecutionPolicy Bypass -File install.ps1
  2. Escolha opção 1
  3. Responda às perguntas
  4. Aguarde conclusão
  5. Acesse http://localhost:5173

PRÓXIMAS VEZES (Apenas Iniciar):
  1. powershell -ExecutionPolicy Bypass -File start.ps1
  2. Acesse http://localhost:5173
  3. Pressione Ctrl+C para parar

⚠️ PRÉ-REQUISITOS:

Antes de executar os scripts, certifique-se de ter instalado:

1. Python 3.8+
   → https://www.python.org/
   → Marque "Add Python to PATH"

2. Node.js 16+ (LTS)
   → https://nodejs.org/

3. PostgreSQL 12+
   → https://www.postgresql.org/
   → Lembre-se da senha do usuário 'postgres'

🔧 TROUBLESHOOTING:

❌ "PowerShell não reconhece o comando"
   → Use o caminho completo do arquivo
   → Ou execute em PowerShell como Administrador

❌ "Acesso negado"
   → Clique com botão direito em PowerShell
   → Escolha "Executar como Administrador"

❌ "Python/Node.js/PostgreSQL não encontrado"
   → Instale a dependência faltante
   → Reinicie o terminal após instalar

❌ "Porta 5000/5173 já em uso"
   → Mude a porta nos arquivos de configuração
   → Ou feche o programa que está usando a porta
